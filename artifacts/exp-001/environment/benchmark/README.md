# EXP-001 benchmark Python environment

This is the reproducibility export for the persistent dedicated benchmark virtual environment at repository-root `.venv-exp001`. It is distinct from the temporary ENV-001 PyMilvus compatibility probe.

- Runtime: CPython 3.14.5, macOS arm64.
- Direct pins: NumPy 2.5.1 and PyMilvus 3.0.1.
- `requirements.lock`: full 16-package transitive resolution generated by uv 0.10.4 for `aarch64-apple-darwin`, with distribution SHA-256 hashes.
- `pip-freeze.txt`: installed environment export, including pip 26.1.1.
- `runtime.json`: interpreter, platform, NumPy, PyMilvus, and resolver identity.

Creation and synchronization commands:

```text
python3 -m venv .venv-exp001
uv pip compile pyproject.toml --python .venv-exp001/bin/python --python-platform aarch64-apple-darwin --generate-hashes --output-file artifacts/exp-001/environment/benchmark/requirements.lock
uv pip sync artifacts/exp-001/environment/benchmark/requirements.lock --python .venv-exp001/bin/python
```

The virtual environment directory is intentionally gitignored; the lock and exports are committed evidence. No Milvus connection was made while creating or validating this environment.
